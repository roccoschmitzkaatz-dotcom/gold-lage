Datenschutzerklärung

Stand: 16.10.2026

Wer nutzt die Anwendung?

Die Anwendung „Lage Gold“ wird nur vom Betreiber des YouTube-Kanals Gold Lage genutzt. Andere Personen melden sich nicht an.

Welche Google-Daten werden verwendet?

Die Anwendung nutzt die YouTube Data API nur, um eigene Videos auf den eigenen Kanal hochzuladen und deren Titel, Beschreibung und Veröffentlichungszeit festzulegen. Es werden keine Daten anderer Nutzer gelesen.

Speicherung

Der Zugangsschlüssel (OAuth-Token) wird nur lokal auf dem Rechner des Betreibers gespeichert. Es gibt keinen Server, keine Datenbank und kein Tracking. Daten werden nicht verkauft und nicht an Dritte weitergegeben.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.

Die Nutzung von Google-API-Daten hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
